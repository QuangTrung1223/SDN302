Separated router mounted at /api/books exposing full CRUD with auto-generated identifiers and standard HTTP status codes (200, 201, 400, 404).

Requirement 3: Middleware Suite

Built-in express.json(), urlencoded, express.static; third-party morgan; custom response-time logger; and x-api-key protection.

Requirement 4: Error Handling

Request body schema validation, catch-all 404 handler, and uniform 4-param centralized error handler tested with deliberate error route.

Endpoints Reference

Method Endpoint Headers Status Description
GET / None 200 OK API welcome message & documentation link
GET /health None 200 OK System health check and server uptime
GET /api/books x-api-key: [key] 200 OK Retrieve all books in the catalog
GET /api/books/:id x-api-key: [key] 200 / 404 Retrieve single book details by ID
POST /api/books x-api-key: [key] 201 / 400 Create new book (title, price > 0, category)
PUT /api/books/:id x-api-key: [key] 200 / 400 / 404 Update existing book properties
DELETE /api/books/:id x-api-key: [key] 200 / 404 Delete a book by ID
GET /api/books/error-test x-api-key: [key] 500 Error Deliberately triggers central error handler
